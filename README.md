### 🛠️ Prerequisites & Setup

1. **Android Studio**: Android Studio Ladybug / Koala or newer with JDK 17+
2. **Clone the Repository**:
   ```bash
   git clone https://github.com/nandhakumar-murugan/android-ai-hub.git
   cd android-ai-hub
   ```
3. **Build & Run**:
   - Open the project directory in Android Studio.
   - Sync Gradle dependencies.
   - Run on an Android Emulator or physical device (API Level 26+).
